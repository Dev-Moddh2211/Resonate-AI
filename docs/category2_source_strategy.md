# Category 2 source strategy

The repository contained Category 1 design documents and configurable prototype assumptions, but no approved lender brochure, policy, customer data, or URL corpus. Therefore Category 2 uses six small, deliberately imperfect files under `data/raw/synthetic/`. Every source is labelled `synthetic_prototype`; none is official policy. The pipeline is designed so an approved source can replace a manifest entry without changing the retrieval contract.
