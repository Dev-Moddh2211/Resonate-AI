# Category 2 source inventory

The authoritative inventory is `data/raw/synthetic/manifest.json`. It covers document, policy, FAQ, CSV/table, objection, and form inputs. All six are English, synthetic prototype sources, version 1.0, effective 2026-09-01. The form contains synthetic PII for redaction testing; the others do not. This assessment demo does not add a real web page or PDF business source: the pipeline supports web/PDF ingestion, but the demo content is intentionally synthetic and must not be presented as supplied company policy. Extraction status and generated counts are in `data/processed/processing_report.json` after running the pipeline.
